# PPT Master — OpenAI compatibility package

This folder packages the upstream-derived PPT Master skill for ChatGPT/Codex plugin import.

Upstream: https://github.com/hugohe3/ppt-master

The original full distribution remains unchanged at `skills/ppt-master`.

To stay under OpenAI archive entry limits, this compatibility package omits optional high-file-count resources:
- `templates/icons/tabler-outline`
- `templates/icons/simple-icons`
- `references/ai-image-comparison`
- `templates/sounds/bigsoundbank`

It keeps the core workflow, scripts, references, templates, three bundled icon libraries, and two sound libraries.
